# 传题系统临时可点击原型

入口文件：`index.html`

## 对应草图结构

- 顶部：系统标题、当前题号、预览、提交审核。
- 左侧上半区：题本上传、Word/PDF 原文块、原文块选择。
- 左侧下半区：解析上传、同版匹配、当前解析摘录。
- 右侧主区：题目结构化录入，包括科目、类型、知识点、年份、省份、难度、题干、问题、选项、附图、答案、解析。
- 最右侧：纵向流程提示，包括上传题本、拆解题干、补全选项、审核入库。

## 已实现的临时交互

- 点击“上传文件”会模拟填入题本/解析文件名。
- 点击左侧原文块会切换当前来源定位。
- 科目、类型、选项模式可以切换。
- 难度星级可以切换。
- 正确答案可以多选。
- 保存草稿、提交审核会更新顶部状态并显示提示。
